# Arch (Arch Labs, Inc.)

> Arch is a private-markets infrastructure platform that centralizes the administration of alternative investments — collecting and classifying investment documents, parsing account statements and cash flows, automating capital-call and distribution workflows, tracking tax documents, and producing standardized portfolio views for investors, wealth managers, family offices, institutional allocators, CPAs and fund managers. The Arch Client API is a JWT-authenticated REST API over holdings, entities, activities, cash flows, tasks, tax documents and Addepar exports.

## APIs
- [Arch Client API docs](https://arch.co/client-api/api-docs/): REST API; base URL https://arch.co/client-api/v0; JWT bearer auth via POST /client-api/v0/auth/token.
